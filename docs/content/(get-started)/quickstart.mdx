## 1. Get the app

Install skcal on [iPhone](https://apps.apple.com/us/app/skcal/id6789390978) or
[Android](https://play.google.com/store/apps/details?id=fit.skcal.app), or open
[app.skcal.fit](https://app.skcal.fit) in a browser. All three use the same
account.

## 2. Sign in

Enter your phone number and the 6-digit code we text you. There's no password,
and a new number creates an account. Your data is scoped to that account.

:::note
Sign-in works with US and Canadian (+1) numbers for now.
:::

## 3. Set your targets

Log a weigh-in and set your daily calorie and protein targets and goal weight.
Today tracks everything against these. You can also start a cut, bulk, or
maintenance phase to see whether your weekly rate of change is on track.

## 4. Log from wherever you are

<Tabs inline>
  <Tab title="App">
    Snap a meal, type "158.2 this morning", or ask the agent "what should I eat
    for dinner?". To lift on a plan, open **Train** and start a mesocycle (see
    [Training](/training)).
  </Tab>
  <Tab title="MCP (agents)">
    ```bash
    claude mcp add --transport http skcal https://app.skcal.fit/mcp
    ```
    Then ask your agent things like "what's my status today?" or "log 160 lb."
    See [Install the MCP server](/mcp-server) for Claude, Claude Code, and ChatGPT.
  </Tab>
  <Tab title="CLI">
    ```bash
    npm install -g @skeptrune/skcal
    skcal login
    skcal weight log 158.2 --note "morning, fasted"
    skcal meal describe "chicken breast + toum, skipped the salad"
    skcal status
    ```
    See [Install the CLI](/cli) for the full command list.
  </Tab>
  <Tab title="HTTP API">
    Create an API key in the app under **profile → API keys**, then:

    ```bash
    curl https://app.skcal.fit/api/dashboard \
      -H "Authorization: Bearer skcal_your_key_here"
    ```
    See [Authentication](/authentication) and the
    [API reference](/api-reference/introduction).
  </Tab>
</Tabs>
